# Astral Rail: Data Sources

Since Revision 2, the characters, Light Cones, enemies, relic sets, items, Trace costs and enemy level scaling in `src/data` are **real Honkai: Star Rail data**. The project is a private, unpublished test project; the user asked for real names and numbers. No binary assets (art, icons, models, audio, fonts) are used: every visual stays procedural or CSS, and the project title stays "Astral Rail".

All of this content is generated by `npm run import:reference` (`scripts/import-reference-data.mjs` and `scripts/reference-data/*.mjs`) from the pinned sources below. The kit modules only describe *mechanics* (which effect uses which reference parameter). Names, descriptions, per-level numbers, Energy, Skill Points, toughness, stats and costs are read from the sources at import time. The importer also **asserts** that every character and Light Cone promotion table matches the growth formula in `rules/progression/default.json` (it does, for all 42).

Each generated record carries a `sources` array (topic, URL, access date). `rules/combat/default.json` and `rules/progression/default.json` cite theirs too.

**Conversions applied by the importer**

- Toughness = reference stance ÷ 3 (a Basic ATK's 30 stance = 10 toughness). The wiki confirms this scale: Voidranger: Reaver 20, Automaton Grizzly 140, Cocolia 180.
- Ability parameters keep their reference numbering: `#3` → `p3`, and description `#3[i]%` → `{p3}%`. Tables cover every level up to the reference max (Basic ATK 10, others 15), so E3/E5 levels are included.
- Character Lv.1 stats are the promotion table's phase-0 base. Lv.80 = base × 7.35 (rounded down in the UI, as in the game).
- Enemy stats = template base × `HPModifyRatio` × EliteGroup ratio; a level's value = that × `HardLevelGroup 1` ratio.

## 2. What was verified

`tests/data/reference.test.ts` pins known in-game values. They include:

- **Lv.80 stats** for Seele 931/640/363/115, Clara 1241/737/485/90, Blade 1358/543/485/97, Bronya 1241/582/533/99, Kafka 1086/679/485/100, Jing Yuan 1164/698/485/99, March 7th 1058/511/573/101 and Natasha 1164/476/507/98.
- **Light Cone Lv.80 stats** for In the Night 1058/582/463, Something Irreplaceable 1164/582/396, Night on the Milky Way, Moment of Victory, Memories of the Past and Arrows.
- **Multipliers:** Seele's Skill 110% → 220% and Ultimate 425% at Lv.10, Kafka's Shock 290%, and Lightning-Lord 66% per hit with 60 SPD and 3–10 hits.
- **Max Energy, Taunt, toughness per ability, and E3/E5 bonuses.**
- **Enemies:** Reaver, Grizzly, Trampler, Frostspawn and Cocolia weaknesses, toughness and RES, plus the Lv.1/Lv.80 level-curve ratios.

## 3. Unverified fields and interpretations

These are either not in the sources or need interpretation. They are listed here rather than guessed silently.

| Field | Status |
|---|---|
| Cocolia's phase transition (`hpThreshold: 0`, `restoreHpTo: 0.75`) | The datamine lists skills per phase but no transition rule. Per the wiki, phase 2 begins when the phase-1 bar is depleted, with Max HP reduced by 25% (HP 75%). Phase-2 toughness **160** is from the wiki infobox, not the datamine. |
| Lance of the Eternal Freeze toughness | The datamine Echo-of-War variants (1002017/1002018) give **40**. The wiki infobox page for "Lance (1)" shows 30, which is a different variant. The datamine value is used. |
| Silvermane Soldier DEF reduction base chance (100%) | From the wiki text. The datamine `ParamList` only holds multiplier, amount and turns. |
| Automaton Grizzly *Enrage Order* (50% base chance, 2 turns) | Chance from the wiki. The turn count is read from `ParamList[1]` (interpretation). |
| Enemy talents with no English name (e.g. Voidranger: Reaver's "Increases SPD after attacking") | **Omitted.** No text-map name and unclear parameters. |
| Enemy Effect Hit Rate | Not modelled per level (the reference scales it through `HardLevelGroup.StatusProbability`). Base 0. |
| Enemy level curve | `HardLevelGroup 1` is used for every enemy. Some reference content uses other groups. |
| Loot tables | The items are real (the "come_from" lists name the faction), but the **quantities and chances are placeholders** (1 and 100%). Drop rates are not in the sources. |
| Banners | 5★ featured units and rates/pity are reference values. The 4★ featured lists are **real-style**: Seele's real banner also featured Hook, who is not in the roster. Pools are limited to the shipped roster. |
| "Greatly increased chance of being attacked" (Clara Ultimate `p1` = 5, March 7th Skill `p5` = 5, Gepard A2 = 3, Moment of Victory `p1` = 2) | Encoded as fractional `aggro` bonuses equal to the reference parameter. The aggro formula itself arrives in Phase 5. |
| Mem's *Baddies! Trouble!* | "4 instances" is encoded as 1 hit + `bounces: 3`. |
| Welt's Skill Slow | Rolled on every hit via `damage.onHit` (Phase 2 fix). |
| Ability Trace levels | The cost tables are real per node and per level, but the per-level ascension gates of ability nodes are not modelled. Major and stat nodes carry their real ascension/level requirements. |
| Character `lore.title` | The sources have no title field, so the character's faction is used. `bio` is the first sentence of the first story entry. |
| Kit versions | The base kits are used. The datamine also contains later "enhanced" variants (8-digit ids such as `11102xx`), which are not imported. |
| Remembrance character | **Trailblazer (Remembrance) with Mem** was chosen over Castorice. Castorice's Ultimate uses a level-dependent "Newbud" cap that doesn't fit a fixed resource without more modelling. |
